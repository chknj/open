SIZE CHART GENERATOR

상품별 실측 데이터를 읽어 상세페이지용 사이즈표 HTML을 만들고, 상품명과 한 줄 코드가 담긴 엑셀 파일로 저장합니다.

01

파일 업로드

↑

파일을 끌어 놓으세요

.xlsx 또는 .csv 파일을 지원합니다.
첫 번째 사이즈 데이터 시트를 자동으로 찾습니다.

아직 업로드된 파일이 없습니다.

입력 기준

  1. 첫 번째 시트는 A열 마스터코드, B열 상품명, C열 사이즈, D열부터 실측값을 입력합니다.
  2. 각 상품 블록 아래의 항목명 순서대로 표가 생성됩니다.
  3. 두 번째 시트는 A열 마스터코드, B열 상품명, C열 정보고시 내용을 입력합니다.
  4. 두 시트의 상품정보고시는 마스터코드가 동일할 때 자동으로 매칭됩니다.
  5. 사이즈가 비어 있는 행과 값이 전부 비어 있는 항목은 출력하지 않습니다.
