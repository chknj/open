SIZE CHART GENERATOR

기존 상세페이지 코드와 실측 데이터를 식별코드로 연결해 ‘상세페이지 → 사이즈표 → 안내문구’ 순서의 최종 HTML을 만듭니다.

엑셀 업로드

↑

파일을 끌어 놓으세요

.xlsx 또는 .xls 파일을 지원합니다.
상세페이지 시트와 사이즈 시트를 자동으로 찾습니다.

아직 업로드된 파일이 없습니다.

입력 기준

  1. 식별코드는 Style Number, 스타일넘버, 스타일번호, 마스터코드, 상품코드, 품번을 인식합니다.
  2. 상세페이지 시트에는 식별코드, 기존 상세페이지 코드, 안내문구를 입력합니다.
  3. 사이즈 시트에는 식별코드, 옵션명 또는 사이즈, 실측값을 입력합니다.
  4. 실측 항목명 행은 사이즈 행의 위나 아래에 둘 수 있습니다.
  5. 빈 실측 항목과 값이 전부 비어 있는 사이즈 행은 출력하지 않습니다.
  6. 최종 코드는 기존 상세페이지 코드, 사이즈표 코드, 안내문구 순서로 결합됩니다.
